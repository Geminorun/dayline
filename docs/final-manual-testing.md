# 统一人工测试指南

七阶段工程完成后按本文统一手测；自动测试、Chromium、文件邮件和 mp-weixin 编译的已知证据见 final-acceptance.md，不能代替真实微信 / 邮件 / 真机验收。测试只用自己的隔离账号，记录浏览器 / 微信版本、设备、网络和时间，不在报告中贴 token、完整验证 URL、密码、OpenID 或私人备份。

## 准备

按 README / self-hosting.md 安装、生成、迁移并启动 API 与 Web，确认 `/health/ready`。使用独立 `_test` 数据库做自动回归，不将生产或已有开发库改成测试目标。不要 reset、drop 或删除卷。`pnpm test:integration` 会构建两个前端并执行真实 PostgreSQL HTTP；维护专项另外创建本轮独立 `_test` 库，防受控时钟影响其他 fixture。

准备 A、B 两个测试邮箱 / 微信身份、两个浏览器 profile 或设备。本机默认 `MAIL_TRANSPORT=file`，只在自己的私目录读取验证和重置邮件并打开链接；这不代表真实投递。真实 Resend 验证时按 `.env.example` 填私有密钥与已验证发件人，记录供应商接受 / 实际收件 / 垃圾箱 / 重发，不把 file 模式结果写成送达。

小程序配置 `apps/miniapp/.env` 的 HTTPS origin、manifest AppID，服务器配置同应用 ID / secret 与真实 `pages/scan/confirm`。先 `pnpm --filter @dayline/miniapp build`，将 `dist/build/mp-weixin` 导入微信开发者工具；再用一台 iOS 和一台 Android 真机，记录微信和基础库版本。无有效配置时应明确提示未配置，不能用假登录绕过。

## 按顺序检查

时间轴紧凑布局补充：准备几条同时进行事项及多条日期不重叠的历史事项，切换全部状态，确认历史复用轨道、同日重叠仍分轨；历史重叠峰值较高时允许额外行。左侧只列当前范围，独立上下滚动，右侧滚轮缩放、空白左右拖动；悬停 / 聚焦标题与横条双向高亮并带入可见位置。短横条与重点色块不得遮挡邻近事项，聚合浮层仍列准确日期。重点使用同尺寸小方块，数量由浅到深分四档；悬停 / 键盘聚焦显示小提示，移出 / Escape 消失，点击或触控可查看真实日期。测明暗主题和极浅自定义主题色，不能所有色阶都消失。点击事项查看紧凑详情，编辑需主动点击铅笔；关窗后保留日期窗口与两侧滚动位置。另测 390 px 窄屏、长标题、1,000 项与日期极值。

1. 游客：两端首次不登录，六分类只初始化一次；建事项、重点历史日、搜索筛选 / 统计、四尺度时间轴、改分类并转移回收站、删除确认 / 取消 / 恢复。退出重进仍是同一游客包，正常统计不含回收站。浏览器另开同 profile 两标签做同修订修改，一方冲突而非静默覆盖。
2. 字符 / 日期：12 个 emoji 分类、100 个 emoji 标题、40 个 emoji 显示名可保存；分别多一个应明确拒绝，不能被原生 UTF-16 maxlength 提前截掉合法字符。测同日起止、闰日、月末、0001 / 0099 / 9999、未来未开始、空结束。UTC / 其他设备时区显示同一北京时间今天。
3. 邮箱 A：公开注册、未验证不能登录私人业务、重发、链接验证后登录；找回通用结果、重置一次成功旧链接重放失败、旧会话失效；改密与当前退出。密码不能出现在草稿 / 通用缓存，邮件 query 从 URL 和 history 清除。
4. 微信 / 扫码：首次主动登录，退出后同微信回同 UUID；换设备仅重新取云端，不上传空包。网页登录码只扫描不登录，需手机明确确认及原网页领取；取消、过期、重放、另一浏览器领取均拒绝。先解析绑定意图的未知微信不能提前造空账号。
5. 游客接入：空云自动接入；有内容先预览，默认双方同标题保留、同名异色分类明确核对。修改选择后不能提交旧计划，保存核对后才开放；取消零云写且本机包保留。挂起响应后继续修改游客包，旧确认只标原修订；断线用原任务查询，不重复复制。
6. 跨端：A 端建 / 改 / 标重点 / 删除 / 恢复，B 回前台立即刷新目标约五秒内看到；前台持续约 30 秒检查，后台停止。切换网络和快速前后台不增加写请求，不以局部列表冒充完整数据。
7. Web 草稿：断网编辑，显示已暂存本机但尚未提交，普通列表 / 导出无草稿。联网只刷新；他端修改后保留旧基准和输入，明确核对冲突再保存或另存。保存期间继续输入、响应不明后读取核对、深链重载、离开前暂存和取消离开均测。复制 / 下载单份草稿与明确放弃不删除云端事项。
8. 账号隔离：A 草稿存在时切 B / 游客不显示 A 私人内容，迟到 A 成功或失败不写 B；另一标签 Cookie 切换导致旧预期账号写被挡住，不能自动重试到 B。重新登录 A 才恢复 A 原稿，损坏 / 配额失败必须持续提示并保留原数据。
9. 文件：游客及账号下载模板，带中文、emoji、逗号、引号、换行、公式前缀和原始单引号 CSV 往返；JSON 保留分类颜色、false 重点和剩余回收站期限。预览零正式写，带 ID / 版本更新、无 ID 新增、缺行不删、疑似重复逐条核对、错误行 / 旧版本 / 过期 / 归属均拒绝整体提交。重复 / 未知结果用原任务恢复，不能重复新增。实际在 Excel / Numbers / LibreOffice 检查编码与公式防护，分别记证据。
10. 绑定 / 合并：未占用身份绑定保 UUID；占用后验证双方才出概要，错密码不退出当前账号。预览保双方同名事项、分类异色区分、true / false 重点和回收站期限；选择变化必须保存 review。取消保双方。确认撤销两边旧会话，邮箱 / 微信都登录统一目标；普通登录不能显示 source 草稿，fresh target 验证及后端映射后只本机复制新分支，保原稿，最后手动核对 / 保存。证明过期仅重验，不丢未过期选择。
11. 注销：先导出 JSON 和单独草稿，勾选确认并 fresh 密码 / 微信证明，服务器确认显示连续七天具体北京时间。两个旧会话都失效；用原身份登录保持 pending，只开放恢复所需操作，普通写 / 导入 / 绑定 / 合并拒绝。直接从注销页导出云端且提示未提交草稿，空 / 损坏缓存不能阻挡服务器导出；Web 微信独有账号也可用专用 reauth QR 撤销。明确撤销需新证明，成功再登录且原稿保留。
12. 注销到期：仅隔离测试用受控 Clock / 专用 fixture，不修改生产时钟。严格到期及锁等待期间跨过期限均不能撤销；维护可重复、失败回滚后重试；删除最终账号连同来源壳、凭据、微信、QR、导入输入 / 回执、合并快照 / 映射，独立 B 不受影响。同邮箱 / 微信之后新建得到新 UUID，旧草稿不会挂给新账号。
13. 键盘 / 布局：Web 1280×720、1440×900、1920×1080，低于 1024 的基本访问；Tab / Shift-Tab、Enter、Escape、离开确认和按钮焦点；时间轴固定名称、横滚、真实日期列表、深滚动筛选不留空白。记录节点数与大数据初次计算 / 可交互耗时，不只看截图。
14. 真机：320–430 宽、系统大字号、键盘遮挡、安全区、横纵嵌套触摸 / 表头同步 / 滑动不误点、系统返回、冷启动 scene、前后台 / 网络切换、杀进程重进游客与低空间 / 存储回调失败。小程序账号输入只承诺当前页面内存，游客包需持久成功；编译和 Vue 组件测试不替代这些。
15. 运维：运行独立镜像 / PG 卷重建和新库恢复脚本，核对 ready 闸门、8 迁移、同源 API / SPA / Cookie / 日志脱敏、恢复后的注销与幂等。容量脚本在没有其他压测 / 编译 / 时钟测试时单独运行，记录样本和实测，不把建议规模当产品硬配额。

每项记录“通过 / 失败 / 未执行”、具体复现步骤、请求 requestId（如适用）和不含秘密的截图。真实微信、Resend、WebKit / Safari 和真机缺条件时保留 pending；不要把“等待用户统一测试”当作省略本机自动验证的理由。
