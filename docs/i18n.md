# 中英文与模块化语言资源

## 用户行为

- Web 的“设置 → 外观”、小程序的“我的”提供简体中文与 English。首次使用跟随设备语言，其他语言回退中文；游客选择保存在本机。
- 登录后读取账号语言偏好，跨设备生效；修改语言立即更新界面，再保存账号偏好。保存失败保留本机选择并提供重试，资料版本冲突先刷新基线，不自动覆盖其他设备修改。
- 表单不因语言切换重建，未提交的标题、邮箱等输入保持原样。事项、分类名、历史草稿不会被自动翻译。
- 日期展示随语言调整，业务日与时间戳始终使用 `Asia/Shanghai`。CSV 列名、JSON 格式、ID、状态码和数据版本保持稳定，文件可跨语言导入。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| `packages/locales/src/shared/<语言>/` | 共享校验、客户端诊断与公开错误，按功能模块分 JSON |
| `packages/locales/src/ui/<语言>/` | 页面、控件、日期和主题的界面词条 |
| `packages/locales/src/server/<语言>/` | 验证邮箱、绑定邮箱、重置密码的主题与邮件内容 |
| `apps/web/src/i18n` | Vue I18n、浏览器语言检测与存储、语言设置 |
| `apps/miniapp/src/i18n` | Vue I18n、小程序存储、原生导航标题和标签栏适配 |
| `apps/api/src/i18n` | nestjs-i18n 资源加载、请求语言与服务端渲染 |

共享包为纯 TypeScript / JSON，不依赖 Vue、浏览器、uni 或 NestJS。运行时使用仓库中的翻译，不调用在线翻译服务。Vue I18n 负责英文单复数与响应式界面，服务端使用独立邮件资源。所有平台差异留在适配器。

界面直接显示时使用 `tr('模块.语义键', {参数})`；通知、错误等持久在内存中的状态使用 `msg(key, params)` 与 `messageRef()`，在显示时翻译。不能把翻译后的字符串用作业务状态，也不能对用户内容调用诊断翻译函数。

## HTTP、账号与邮件

- 客户端每次请求发送 `Accept-Language: zh-CN` 或 `en`。后端按请求头中的优先顺序选择支持的语言族，如 `en-US` → `en`、`zh-Hans` → `zh-CN`；缺省回退中文，响应带 `Content-Language`。
- 语言保存在请求独立的 AsyncLocalStorage 与 NestJS 上下文中，覆盖原生 Better Auth 中间件，不能用全局可变语言状态。
- 公开错误保留原有 `code`、`details`、请求 ID，并返回本地化的 `message`；业务错误可附加 `messageKey` 和数字 `params`。客户端仅接受本地白名单中的公开错误键与有限数值参数，未知错误回退安全提示，不直接展示上游异常或内部标识。限流继续以 `Retry-After` 驱动倒计时。
- `GET /api/v1/me` 返回 `locale: 'zh-CN' | 'en'`。`PATCH /api/v1/me` 接受 `displayName`、`locale` 至少一个，以及必填 `expectedProfileVersion`；沿用身份校验与资料版本锁，语言变更不改名、不改变记录快照版本。
- 数据迁移 `20261029100000_user_locale` 为既有用户添加默认中文偏好；不需要新环境变量。部署照常执行迁移。
- 邮件优先使用收件账号保存的语言。新账号注册事务尚未对独立读连接可见时沿用当前请求语言；重发验证、重置密码、绑定邮箱仍使用既有账号偏好。邮件业务目的使用固定标识，不通过翻译后的主题或按钮文本判断。

## 新增文案与验证

1. 在对应模块的 `zh-CN` 与 `en` JSON 中添加同名键与相同参数；使用完整句子，避免拼接中文语序。
2. 数量文案交由 Vue I18n 单复数适配；多计数摘要优先使用明确的字段标签。服务端邮件资源不混入 Vue 专用语法。
3. 新增小程序页面时同步 `pages.json`、`i18n/native-pages.ts` 与 `locale/` 的原生标题。
4. 运行 `pnpm check:i18n`（已加入 CI），检查两种语言的键、参数、静态引用、原生标题一致性及英文残留中文；随后运行相关类型检查、测试与双端构建。

语言测试覆盖输入保留、通知动态切换、英文单复数、设备语言与原生标题、资料冲突重试、跨账号旧响应、真实 PostgreSQL 注册与邮件、多请求语言隔离。微信真机显示仍由开发者工具及设备验收。
